# ☀️ The Joy Grid

A minimalist, daily web game designed to cultivate intentional focus on simple human moments.

## 🧭 How It Works
The game presents a daily matrix divided into three distinct operational layers:
*   🏃‍♀️ **Life Goals:** Active daily priorities (movement, creation, mindful choices).
*   🌿 **Grounding Actions:** Randomly seeded daily practices to anchor awareness.
*   ✨ **Higher Truths:** Space for higher contemplation, offering beautiful daily philosophical quotes upon interaction.

## 🛠️ Tech Stack
*   **Frontend:** Pure HTML5, Semantic CSS3, and Vanilla JavaScript (ES6+).
*   **Architecture:** Zero external dependencies. Uses a deterministic time-based seeding algorithm to generate identical grid variations for all players globally on any given day.
*   **Deployment:** Hosted natively via GitHub Pages with a custom domain routing matrix.
